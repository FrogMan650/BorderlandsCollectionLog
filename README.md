# Borderlands Collection Log
A desktop app for collecting unique items in all Borderlands games.<br>
Items can be filtered by various criteria such as type of item, rarity, game, and whether you've obtained it or not.<br><br>
__7-19-26 1.1.1 Release__<br>
* All unique items from Borderlands 1, 2, TPS, 3, and 4 are included and have been updated.
* Significant improvements to performance when loading item cards
* Added the "Indicator Tray" to item cards
  * Many different custom made indicator icons will be visible based on variuous different things:
    * Item Wiki link moved here
    * Item LootLemon link moved here
    * World drop
    * DLC
    * Mission reward
    * BL2 Game Mode required
    * BL2 Currency the item can be bought with
    * BLTPS Grinder availability
    * BL3 Mayhem level required
    * BL3 Earl indicator if the item can be reobtained from the Veteran Rewards Vending Machine
    * BL4 Phosphene indicator
  * Every indicator has a tooltip with additional information
  * Reworked the majority of the item data I had
* Added a "Phosphene mode" where only items with a phosphene variant will be shown
* Added the ability to have multiple "Profiles" or saves
  * Several buttons added to the settings menu to create, rename, delete, etc. profiles
* Reorganized the banner at the top
* Other various cleanup tasks
* Updated the readme with far more info
* Now comes bundled in an installer
  * Executable, readme, and item data files are installed to C:/Program Files/Borderlands Collection Log
  * Settings, logs, and profile data files are created in C:\Users\User\AppData\Local\BorderlandsCollectionLog
    * This directory and subsequent files are created on first launch of the App
