# Borderlands Collection Log
A desktop app for collecting unique items in all Borderlands games.<br>
Items can be filtered by various criteria such as type of item, rarity, game, and whether you've obtained it or not.<br><br>
__8-15-26 1.2 Release__<br>
* Updated the BL4 item data with new items from the most recent DLC
* Changes to the indicator tray
  * Added a Vault Card indicator for which card the item is from as well as how many keys/tickets it costs
  * Added a Mod indicator
    * Can be given custom information to display in the tooltip
    * When the indicator is clicked, if a link was included in the mod attribute text, the link will be opened in a browser
  * Changed the mission indicator to display mission information in the tooltip rather than on the item card
  * Centered the indicator tray at the bottom of the item card
* Reorganized the banner at the top (again)
  * New Profile quick swap dropdown
  * Moved resource links to the right, next to the Settings button
  * Added a MentalMars resource link
* Added the Item Picker
  * Located on the banner next to the Profile quick swap dropdown
  * This replaces the Item pane with a pane that will randomly choose one item card from the filtered item cards
* Changed a few of the miscellaneous filters to be a little more relevant
* Other various cleanup tasks
