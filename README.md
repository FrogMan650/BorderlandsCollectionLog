# Borderlands Collection Log
Available for Windows and Linux!<br>
Borderlands Collection Log is an application made for collecting and keeping track of unique items in all main line Borderlands games. Every item is displayed similar to an item card from Borderlands 2, in layout and style. These cards can be filtered by various criteria such as game, item type, rarity, etc. <br>
With The Hunt being a big inspiration for creation of this App, Hunt points as well as a dedicated Hunt Mode are included, as well as the App keeping track of when you collected the item. And if you're not sure which item to go for next the App can even help you with that, thanks to the item picker.
